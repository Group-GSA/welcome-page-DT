# welcome-page-DT

Welcome page for GroupGSA's DT (Design Technology) team: what the team does, what to ask, how to reach it, and who is in it.

- The page is a single self-contained file: `index.html`.
- It deploys to GitHub Pages through `.github/workflows/deploy-pages.yml` on every push to `main`.
- One-time setup: **Settings → Pages → Source → GitHub Actions**.

Contact: DT@groupgsa.com
