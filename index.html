    06DT

    House rules

    Non-negotiable
    01

    Never upgrade a central

    Work in the Revit version the project is already in. Upgrading is one-way, for everybody on the model.

    02

    Sync often — say so first

    Where the project has a Teams channel, tell the others before you sync instead of syncing into each other.

    03

    Can't see it? Don't hack it

    A project missing from ACC or Forma is a request to DT, not something to work around.

    04

    AutoCAD from the desktop icon

    The icon loads GroupGSA's settings. Any other route starts AutoCAD without them — silently.

    05

    Ask the team, not a person

    DT@groupgsa.com reaches all four of us. That's the fastest answer you'll get.
